## If the launch looks wrong

- **The antivirus holding area has the file.** Bring `setup` back from quarantine and launch it inside the extracted folder.
- **SmartScreen blocks the first launch.** You may see a warning because the file is unsigned. Click 'More info' followed by 'Run anyway' to proceed.
- **`setup` was carried off without the rest.** Put it back with the other files, or extract the archive another time.
- **Double-click never left the zip.** Extract before the next try. The archive is still compressed.
- **Controlled Folder Access Blocked.** To resolve this, allow `setup` in the Controlled Folder Access settings, or extract the files to a folder that is already trusted.

## A bit of context

Using the program means unpacking the zip and running the file named `setup`, while a later build is another archive downloaded and started the same way.

Running from a standard user account is enough. No admin prompt is involved.
